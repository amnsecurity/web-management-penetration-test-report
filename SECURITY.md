# Security Policy

This repository contains a sanitized public case study. No real client identifiers, authentication secrets, credentials, or infrastructure values are disclosed.

For responsible disclosure, security consulting inquiries, or private assessments, contact AMN SECURITY via the channels listed above.

**What this repository does NOT contain:**
- Usernames or passwords used during testing
- Private keys or certificate material
- Session tokens or authentication cookies
- Client-identifying information
- Proof-of-exploitation tokens (flags, markers, or ownership proofs)

**What this repository DOES contain:**
- Technical vulnerability descriptions (CWE-classified)
- Attack chain narrative with timeline
- Remediation recommendations
- Sanitized proof-of-concept scripts demonstrating the exploitation technique
- Scan methodology and analysis
